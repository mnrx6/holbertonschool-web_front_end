# Advanced HTML

## Description
This project focuses on learning HTML5 and building web pages using semantic HTML elements without CSS.

## Learning Objectives
- Understand the structure of an HTML5 page.
- Use semantic HTML tags.
- Create headings, paragraphs, and lists.
- Add links, images, audio, and video.
- Create tables and embed external content.
- Write clean and valid HTML code.

## Technologies
- HTML5

## Project
The project uses **Techium**, a fictional digital agency, to practice building structured web pages.
